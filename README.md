# WHO 第五版造血與淋巴組織腫瘤分類導覽 (WHO-HAEM5)

以細胞系譜（Lineage-based）為核心的 WHO 5th Edition（WHO-HAEM5）互動式分類樹與診斷標準速查網頁。

## 功能特色
- **六大章節專屬分色樹狀圖**：涵蓋 Ch.2 骨髓、Ch.3 組織球／樹突細胞、Ch.4 B 細胞、Ch.5 T/NK 細胞、Ch.6 淋巴組織基質腫瘤、Ch.7 遺傳性腫瘤症候群。
- **Essential & Desirable 診斷標準**：點擊任一疾病即可檢視完整分類路徑、必要標準與建議／輔助標準。
- **標記物與基因即時反查**：支援中英文診斷名、縮寫及免疫／基因標記（如 `SF3B1`, `MYD88`, `CD30`, `BRAF`, `EBER`）搜尋。
- **直連血液科各疾病個論**：各疾病卡片內建連結，可直接跳轉至對應 NCCN 個論網頁之診斷評估與治療章節。
- **淺色／深色主題切換與入口網返回列**：與 `hematology-portal` 系列維持一致操作體驗。
